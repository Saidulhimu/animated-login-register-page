## ✨ Key Features
- 🔄 **Smooth Overlay Animation:** Seamless toggle transition between Sign In and Sign Up panels.
- 🎨 **Golden Hour Aesthetic:** Custom gradient styling and modern typography.
- 📱 **Fully Responsive:** Adapts cleanly across mobile, tablet, and desktop screens.
- 🔒 **Interactive Form Elements:** Styled input validation states and social icon triggers.

## 🛠️ Tech Stack
- **HTML5:** Semantic structural layout
- **CSS3:** Custom keyframe animations, Flexbox, and CSS variables
- **JavaScript:** DOM manipulation for panel toggling
